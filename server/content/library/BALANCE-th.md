# ชื่อชุด Enchant และบาลานซ์ Luma

สูตรในเอกสารนี้เป็น **แบบออกแบบ v1 ที่ยังไม่เปิดทำงาน** มีข้อมูลเครื่องอ่านใน [balance.json](balance.json)
Core v0.6 ทำ native enchant ของ starter 3 ชิ้นและ archive v1/v2 แล้ว; starter ขยับเป็น Sharpness II/Sweeping I,
Efficiency III/Fortune I, Protection II/Thorns I พร้อม Unbreaking II ตามที่ต้องการให้ดูมีพลังขึ้น
เพิ่ม [มอนสเตอร์ตามความลึก](../../../fantasycore/MONSTERS-th.md) เพื่อรองรับของที่ดีขึ้น; ยังไม่ได้เปิดใน Minecraft runtime
profile ของแพ็กทุกชุด/ทักษะ 17 ชุด/ขั้น II–III เป็น blueprint; ห้าม drop JSON นี้เป็น provider config หรืออ้างว่าทั้งหมดเปิดแล้ว

## เป้าหมายความรู้สึกเมื่อเล่น

ของระดับต้นควรใช้ออกเควสได้จริง ของกลางทำให้ผู้เล่นรู้สึกว่าอัปเกรดแล้ว และของปลายมีทักษะเด่นให้เลือกใช้ตามจังหวะ
ผู้เล่นที่เลือกสไตล์มังกรหรือจอมทัพใช้ power budget เดียวกันเมื่อมีระดับเดียวกัน; ไม่บังคับซื้อ skin เพื่อเล่น build นั้น
ชื่อชุดในแคตตาล็อกบอกธีม ส่วนระดับนักเดินทาง/ผู้ชำนาญ/จ้าวรูนบอกพลัง
ค่า `balanceProfile` ใน catalog เป็นระดับเสนอสำหรับจังหวะที่เปิดชุดนั้นครั้งแรก เปลี่ยน skin ไม่เลื่อนระดับพลัง

## 1. ระดับพลังและราคาในเกม

| ระดับ | จุดเริ่มต้นที่เสนอ | ดาบ/ธนู | เกราะ | เครื่องมือ | ราคา Gold ต่อชิ้น | Token เควส |
|---|---|---|---|---|---:|---:|
| นักเดินทาง I | เควสเมือง/โรงตีเหล็ก | Sharpness II / Power II + Unbreaking II | Iron Protection II/Thorns I + Unbreaking II | Efficiency III/Fortune I + Unbreaking II | 200–400 | 0–2 |
| ผู้ชำนาญ II | เควส 6–10 รอบ + วัตถุดิบ | Sharpness III / Power III + Unbreaking III | Diamond Protection III/Thorns I + Unbreaking III | Efficiency IV/Fortune II + Unbreaking III | 1,500–2,800 | 6–10 |
| จ้าวรูน III | เควสกิลด์/บอสกลุ่ม | Sharpness IV / Power IV + Unbreaking III | Diamond Protection IV/Thorns II + Unbreaking III | Efficiency V/Fortune III + Unbreaking III | 5,000–9,000 | 18–24 |

ขั้น II/III และ token เป็นเป้าราคา/ระบบอนาคต; Core มีเฉพาะ starter 3 สูตรราคา 200/300/400 Gold ตามคู่มือ Craft
token ไม่มีช่องทางซื้อเงินจริง; quest reward ที่มีพลังห้ามแปลงเป็น SKU cash ผ่านคำสั่ง config โดยไม่ตรวจประเภท
ไม่ใช้ enchant ระดับ 10/100 หรือรวม stat พิเศษหลายระบบจนคูณกัน
เว้น Netherite และพลังเพิ่มเติมนอกตารางไว้หลังมีข้อมูลเศรษฐกิจ/ความยากจริง; ค่าระดับสูงใน blueprint ยังไม่ใช่สูตรที่เปิดแล้ว

ตัวอย่างสูตรเสนอ (ยังไม่เป็น recipe ที่เปิดใช้):

- ดาบผู้ชำนาญ: ดาบรูนเริ่มต้นที่เป็นของผู้เล่น + Diamond 8 + Lapis 24 + token ช่าง 6 + Gold 1,800
- เกราะจ้าวรูน: เกราะผู้ชำนาญ + Diamond 16 + Amethyst shard 24 + token กิลด์ 24 + Gold 7,500; client เก่าที่ไม่รู้จัก material ต้องมี input fallback ของ Core
- อีเต้อผู้ชำนาญ: อีเต้อจันทร์เดิม + Diamond 6 + Iron 24 + token นักขุด 6 + Gold 1,500
- เบ็ดผู้ชำนาญ: เบ็ดเดิม + String 16 + Lapis 24 + token ประมง 6 + Gold 1,500

อัปเกรดต้องย้าย identity ของชิ้นเดิมใน operation เดียว: snapshot ก่อน, หัก input/Gold, freeze output, journal, mailbox
ไม่รับ item จากเทียบชื่อ ไม่หักของแล้ว `give` โดยไม่มีใบรายการ; recovery ที่ไม่แน่ใจส่ง REVIEW
Core v0.6 เพิ่ม native enchant ของ starter 3 ชิ้นตามขั้น I และ lookup revision v1/v2 แล้ว; ส่วน profile ทุกชุด/trait ยังเป็น blueprint
ดู [ENCHANTS-th.md](../../../fantasycore/ENCHANTS-th.md) สำหรับเพดาน factory, snapshot รุ่นเก่า, การอัปเกรดและ runtime QA

ชื่อไทยเป็นคำอธิบายของ Luma ไม่ใช่การลงทะเบียน enchant ใหม่ และไม่เปลี่ยนชื่อ enchant vanilla ของผู้เล่นทุกคน
ค่าจริงเก็บ Enchantment key/level ฝั่ง server; lore ที่แก้ชื่อไม่เพิ่มพลัง
ให้ factory ตรวจ material, max level และคู่ enchant ขัดกันก่อนออก item; ไม่ใช้ unsafe enchant แบบ allow-all
จอบ/ขวานสำหรับอาชีพใช้ profile tool และไม่เติม sword profile อีกชุดในชิ้นเดียว
shield ใช้ Unbreaking ตามระดับ ไม่เติม Protection ให้โล่หรือ Efficiency ให้คทา

ปิด Mending/Unbreakable ในชุดนี้เพื่อให้ช่างซ่อมยังมีบทบาท ใช้ค่าซ่อมเดิมที่รักษา serial, enchant, model และ lore
เกราะ PAPER/LEATHER จาก asset หลายชุดมีไว้แสดงผล อย่านับว่าเป็น Diamond armor เพียงเพราะชื่อเหมือน
หาก provider บังคับ material ต้องสร้าง pack/model สำหรับ base ที่ถูกต้องหรือใช้ visual layer ที่ไม่แทน item gameplay เดิม

## 3. ทักษะประจำชุดที่เสนอ

เลือกรูนประจำชุดได้เมื่อถึงระดับ II ต้องใส่ชิ้น gameplay ในชุดเดียวกันอย่างน้อย 3 ชิ้น และมี rune unlock จากเควส
เปิดใช้ทักษะได้สูงสุด **หนึ่งชุด**; cosmetic wardrobe ไม่ถือเป็น gameplay set
ทักษะทั้งหมดปิดใน PvP, spawn, ธนาคาร และพื้นที่ที่ policy ไม่อนุญาต
cooldown อยู่ที่ UUID ผู้เล่น ใช้กลุ่มร่วม ไม่รีเซ็ตเมื่อเปลี่ยนอาวุธ/ถอดเกราะ/เปลี่ยน skin/ออกเกม

| ชุด | ชื่อทักษะ | ผลครั้งหนึ่ง | Cooldown |
|---|---|---|---:|
| ธาราฟ้า | พรธาราฟ้า | ฟื้น HP ตัวเอง 3 (1.5 หัวใจ) | 24 วินาที |

กติกา execution ก่อนเขียนจริง:

- next-hit buff มีเวลาใช้ 5 วินาทีและใช้ได้ครั้งเดียว ไม่ค้างจนกลับเข้า lobby; cooldown เริ่มเมื่อ activate
- ความเสียหายเพิ่มแบบ flat แยกจาก crit และไม่เรียก trigger ของทักษะอีกรอบ; multiplier สูงสุด 15% ไม่คูณ chain
- heal ต้องไม่เกิน max HP, ไม่ได้เลือดจาก armor stand/NPC/player/สัตว์เลี้ยง/mob ที่ผู้เล่นเลี้ยงไว้ฟาร์ม; ไม่เพิ่ม loot จากคนเก็บ last hit
- Absorption ใช้สูงสุด 4 HP ไม่สะสมจากสองแหล่ง; การ refresh ไม่สร้างห่วงโซ่เกราะถาวร
- AoE ตรวจ LOS/WorldGuard/สมาชิกปาร์ตี้/target immunity ก่อน damage; ไม่ทำให้บล็อกติดไฟหรือ claim เสียหาย
- dash ตรวจ swept collision ตลอดเส้นทาง, chunk loaded, min/max Y, ประตูปิด, barrier และ border; พบจุดชนหยุดก่อนชน ไม่ teleport ข้ามกำแพง
- บอสอาจไม่รับ taunt/snare; บอก immunity ใน tooltip ไม่ให้ทักษะควบคุมหยุดบอสถาวร
- party heal เลือกตามระยะและ HP ต่ำสุดอย่างแน่นอน ไม่เรียก task ต่อทุกชิ้นเกราะทุก tick
- admin test bypass แยก permission ไม่มี bypass ที่ผู้เล่นซื้อจากเว็บได้; ทุก activation เก็บ log ตามความจำเป็น ไม่ log 20 ครั้ง/วินาที

## 4. รางวัลเควสและการขาย

1. เควสธนาคารสอนฝาก/ถอน ให้ token เมือง + preview ธาราฟ้า; ไม่นำธุรกรรมฝากเงินจริงในเกมไปนับซ้ำเป็นรางวัลไม่จำกัด
2. เควสช่างเริ่มต้นแจกวัสดุทำชุด I; เควสซ่อมนับ operation สำเร็จที่จำกัดวัน ไม่รับการทำลาย/ซ่อมชิ้นเดียววนเพื่อฟาร์ม
3. เควสฟอสซิลสะสม marker UUID 3 จุดที่ server สร้าง ให้เลือกไดโนเสาร์หนึ่งตัว; marker ไม่ใช่ rename item
4. เควสครัวนับเฉพาะ item ที่ส่งสำเร็จและ journal แล้ว; เลือกสูตรอาหาร/ของแต่งครัวเล็กหนึ่งชิ้น
5. เควสกิลด์ให้ token II/III และสุ่ม appearance จาก pool ที่แจ้ง; cooldown และคีย์ประจำวันไม่เปลี่ยนเมื่อสลับ client version
6. กุญแจห้าดาราใช้ในกิจกรรมเท่านั้นในแบบนี้; สินค้า cash ขายรูปลักษณ์หรือของตกแต่งที่ระบุแน่นอน

ราคาเว็บ 79–219 บาทเป็นข้อเสนอของ entitlement **หนึ่งชุดธีม** ไม่รับเงินจริงในขั้นนี้
ต้องจัดรายการ SKU จริงให้ไม่รวม model helper เช่น `_self`, `_opening`, `_cosmeticscore` เป็นของที่ผู้เล่นใช้ซ้ำแยกชิ้น
การแต่งตัวต้องรักษา stats/serial ของ gear เดิม; ไม่ใช้การซื้อ skin สร้างดาบใหม่ให้ผู้เล่น
เครื่องครัวและเฟอร์นิเจอร์ร้านมีบทบาทตกแต่งเท่านั้น ไม่ให้ storage/production multiplier เกินของเล่นหาได้จากเควส

## 5. เกณฑ์พิสูจน์บาลานซ์

ใช้ชุดทดสอบเดียวกันต่อระดับ ตั้งผู้เล่น HP20, อาหารเต็ม, ไม่ใส่ potion, ไม่มี pet bonus, ปิด trait เมื่อตรวจ base
โจมตีเมื่อ cooldown เต็ม วัดอย่างน้อย 30 รอบและรายงาน median/p95; แยก hit ปกติและ crit

| สิ่งที่วัด | เกณฑ์ยอมรับที่เสนอ |
|---|---|
| ดาเมจดาบ III เทียบ I | เห็นผลประมาณ 15–35% ต่อ hit; ไม่มี one-shot ผู้เล่นสุขภาพเต็มจาก perk |
| ความทนทาน II/III | คุ้มค่าซ่อมกว่า I โดยค่าซ่อมไม่เกินส่วนที่ประหยัดได้จากอาชีพ/เควสปกติ |
| เปลี่ยนธีมในระดับเดียว | base DPS/armor ไม่เปลี่ยน; ความต่างมาจาก active trait ที่เลือก |
| บอสในเควส III | ผู้เล่น 3–5 คนทำได้จากชุด II ถ้ารู้กลไก; III ลดเวลาที่ใช้แต่ยังต้องทำกลไก |
| การใช้ perk | ทุก perk มีสถานการณ์ที่ช่วยได้จริง; ใช้ไม่มีเป้าหมายไม่เกิดรางวัล/ข้อมูลผิด |
| ซื้อของร้าน | เปลี่ยนภาพ/สิทธิ์ตกแต่ง; base stats, quest token และ cooldown เดิม |
| เศรษฐกิจ | ยอด Gold/วัสดุหักครบต่อ operation ไม่เติม reward ซ้ำหลัง restart |

เกณฑ์เปอร์เซ็นต์เป็นเป้าทดสอบ ไม่ใช่ผลวัดแล้ว
หากระดับต้นดูอ่อน ให้ปรับ base/วัสดุ/ความยากศัตรูก่อนเพิ่ม perk ทุกชิ้น; หากปลายแรงไป ปรับเฉพาะ profile version ใหม่และให้สิทธิ์ของเดิมตามแผนอัปเกรด
ใช้ข้อมูลการตาย เวลาเควส ค่าเฉลี่ย Gold ต่อชั่วโมง และต้นทุนซ่อมจากผู้เล่นทดสอบจริงก่อนล็อก production
